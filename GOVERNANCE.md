# Gobierno y mantenimiento del proyecto oficial

## Dirección funcional
El repositorio oficial **nicoarg87/plasma-smartbar** es administrado por su mantenedor. El mantenedor establece visión, experiencia de uso, prioridades y aprobación final de cambios de diseño, ayudándose de colaboradores para ingeniería, pruebas y revisión de código.

## Qué puede hacer la comunidad
- Leer el código, reportar fallos y sugerir mejoras.
- Crear forks y redistribuir versiones propias de acuerdo con la GPL-3.0.
- Enviar pull requests para que el proyecto oficial considere integrar cambios.
- Participar en discusiones técnicas y documentación.

**Ningún fork ni PR modifica la versión oficial sin una integración autorizada.** Mantener una versión distinta no convierte esa versión en oficial.

## Cómo se incorporan cambios
1. Registrar issue o propuesta; referirse a la [Constitución técnica](docs/CONSTITUCION_TECNICA.md) y al [Manual Maestro](docs/MANUAL_MAESTRO.md).
2. Para bugs o compatibilidad: describir reproducción, entorno y prueba de no regresión.
3. Para cambio funcional o visual importante: esperar aprobación de diseño antes de implementar.
4. Enviar PR con cambios acotados y pruebas; solicitar revisión técnica y funcional.
5. El mantenedor autorizado acepta, pide cambios o rechaza. Las versiones oficiales se etiquetan y documentan.

## Reglas de seguridad y acceso
- No conceder permisos de escritura ni de administración a desconocidos o solo por tener aportes valiosos.
- Habilitar protección/reglas de la rama main y revisar permisos desde GitHub Settings (tarea de configuración externa a este archivo).
- No añadir secretos, claves, datos personales ni código de terceros sin verificar licencias.
- Nunca ejecutar código de PR no confiable con secretos de GitHub.
- Mantener criterios de rendimiento, accesibilidad y compatibilidad como bloqueadores de publicación.

## Cambios a la constitución
Requieren discusión pública o privada documentada y aprobación explícita del mantenedor. Se actualizan en un PR separado con explicación de los requisitos alterados y su impacto.

## Licencia y autoría
El repositorio ya incluye LICENSE bajo GPL-3.0. La licencia permite usar y crear derivados con sus condiciones; **no restringe la libertad de crear forks**. El control del repositorio oficial es independiente de los derechos sobre contribuciones de terceros y de eventuales marcas.
